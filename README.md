This is my VR Room project, it is heavily based on my bedroom from back home (although I took creative liberties. but that's not important)
I went for relatively simple and low poly assets as it's one of my favorite aesthetics but rest assured there is care and detail put into this room.
I hope you all enjoy even if it's not that big!
